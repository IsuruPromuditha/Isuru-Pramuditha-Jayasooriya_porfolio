# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.

# Full-Stack Developer Portfolio

[![Portfolio Live](https://img.shields.io/badge/Repository-IsuruPromuditha%2Fportfolio-cyan?style=for-the-badge&logo=github)](https://github.com/IsuruPromuditha/portfolio)

A modern, responsive personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**. Designed with a cyber-inspired dark theme, dynamic typewriter effects, glassmorphism, and custom UI components to showcase full-stack development projects, interactive code samples, and technical skills.

---

## ✨ Key Features

* **Dynamic Hero Section:** Custom typewriter role rotation, call-to-action buttons, and an overlapping cutout avatar with custom ambient glowing effects.
* **Interactive Code Terminal:** Simulates a developer terminal displaying live tech stacks and personal stats.
* **Responsive Layout:** Tailored for mobile, tablet, and desktop viewports using modern flexbox and grid architectures.
* **Cyber Aesthetic UI:** Built using dark slate tones, neon cyan highlights, backdrop blur effects, and smooth hover interactions.
* **Project Scope Estimator & Showcase:** Built-in modular components to demonstrate completed projects and interactive estimation features.

---

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS
* **Icons & Animation:** Lucide React, Custom CSS Keyframes & Filters
* **Deployment:** Vercel / Netlify / GitHub Pages
